# Publication de mon portfolio professionnel sur GitHub Pages

## 1. Identification générale

- **Auteur** — Timothy Valentin, BTS SIO option SISR.
- **Cadre** — Projet personnel — BTS SIO SISR.
- **Période** — Septembre 2026.

## 2. Contexte et objectifs

Présenter mon parcours, mes réalisations et mes compétences en ligne à partir de fiches faciles à maintenir.

## 3. Démarche et environnement technique

**Outils** — Astro, Markdown, Git, GitHub Actions et GitHub Pages.

Après un premier essai sous WordPress, j’ai retenu un site statique. Les fiches sont écrites en Markdown, Astro génère les pages, puis GitHub Actions construit et publie le site sur GitHub Pages après les mises à jour du dépôt.

## 4. Rôle et contribution personnelle

J’ai défini la structure et le contenu du site, rédigé les fiches et géré la publication et les mises à jour.
