# Validation sur maquette physique

Ce compte rendu synthétise les vérifications décrites dans le portfolio et le rapport de stage. Le schéma est public et simplifié.

| Étape | Contrôle documenté |
| --- | --- |
| Physique | Vérifier le câblage et l’état des interfaces avant d’examiner les couches supérieures. |
| Liaison | Examiner les VLAN, les liens trunk et la table MAC. |
| Réseau | Tester la connectivité de proche en proche, puis vérifier le routage et la table ARP. |
| Filtrage | Examiner l’ordre et la portée des règles d’accès. |
| Retest | Refaire un test de bout en bout après correction. |

**Résultat rapporté** — Les pannes injectées par le tuteur ont été traitées sur la maquette en appliquant cette démarche. La proposition d’infrastructure issue des entretiens a été présentée devant un jury de spécialistes.
